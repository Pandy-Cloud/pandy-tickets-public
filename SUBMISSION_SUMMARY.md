## 🎯 Key Features Documented

### Platform Capabilities

- ✅ Event search and discovery
- ✅ Ticket sales (card + bank transfer)
- ✅ **Assisted receipt review** (NOT automatic - organizer approves)
- ✅ QR code check-in (offline in mobile apps)
- ✅ Sales reports and analytics
- ✅ Numbered seating with 3D venue views
- ✅ Organizer API (read-only and write with permissions)

1. Never claim automatic receipt review (always manual approval)
2. Never process payments directly (use checkout URLs)
3. Prices always in quetzales (GTQ)
4. Offline check-in only works in mobile apps
5. API keys are sensitive (environment variables only)
